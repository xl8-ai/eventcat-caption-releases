# EventCAT Floating View

A small desktop app that shows an EventCAT session's live translated captions in a window floating on top of everything else on the screen, including full-screen slideshows.

EventCAT 세션의 실시간 번역 자막을 화면 맨 위에 띄워 주는 데스크톱 앱입니다. 전체화면 슬라이드 위에도 떠 있어요.
